# Agent guide

doc-extract is a native text-extraction library for Node.js and Bun. Rust parsers run in-process through N-API. The public package name is `@alexstep/doc-extract`.

## Architecture

- `src/` is the Rust crate `doc-extract` (`crate-type = ["cdylib"]`). Format parsers live in `src/formats/`. Format detection (magic bytes, ZIP sniffing, extension hints, unknown-content policy) lives in `src/detect.rs`. N-API exports are in `src/lib.rs`.
- `index.js` and `index.d.ts` are generated by `@napi-rs/cli`. Do not edit them by hand. `napi build` rewrites them.
- `doc-extract.js` and `doc-extract.d.ts` are the public JavaScript API: file paths, `http(s)` URLs, buffers, size and concurrency limits, and soft failures. Content problems resolve to `""`. Missing files, size limits, and network errors throw.
- `fixtures/` holds small documents used by Rust and JS tests. `fixtures/broken/` holds empty and truncated files. Regenerate the synthetic office fixtures with `python3 scripts/generate-fixtures.py` (`xlwt` is required for `sample.xls`). Do not replace `sample1.pdf` or `sample2.pdf`; those are real PDF fixtures.
- Platform binaries (`doc-extract.<platform>.node`) and `target/` are build output. `.gitignore` already excludes `*.node`.

Supported extractors: PDF, DOCX/DOCM, XLSX/XLS/ODS, PPTX/PPTM, ODT, RTF, EPUB, FB2, ICS, VCF, JSON/JSONL, CSV/TSV, HTML/XML, plain text, and PKPass. Legacy `.doc`, OCR, and images are intentionally unsupported.

## Build

Requirements: Rust stable (see `rust-toolchain.toml`), Node.js ≥ 18, Bun ≥ 1.3.

```bash
bun install --frozen-lockfile
bun run build              # napi build --platform --release
cargo build --release      # Rust crate only; does not write the .node addon
```

`bun run build:debug` is the same addon without `--release`.

## Tests

```bash
cargo fmt --all -- --check
cargo clippy --all-targets -- -D warnings
cargo test
bun test                                       # full JS suite, including Bun-only tests
node --test __tests__/formats.test.mjs         # one case per supported format, plus broken/empty/unicode
```

`__tests__/formats.test.mjs` uses `node:test`, so both Node and Bun can run it (`bun test __tests__/formats.test.mjs` when the installed Bun understands `node:test`). The rest of `__tests__/` uses `bun:test`.

A local timing check, not a CI gate:

```bash
node scripts/bench.mjs
bun scripts/bench.mjs
```

## Rules

- Do not break the public API in `doc-extract.d.ts` or the behavior of `doc-extract.js` (`extractText`, `parsePkPass`, the setters, and the soft-fail vs throw split).
- Do not commit `*.node`, `target/`, `npm/`, WASI bundles, or `node_modules/`.
- Do not bump `version` in `package.json` or `Cargo.toml` unless a release was explicitly requested.
- Do not publish to npm or crates.io from an agent. The tag-only publish job is `.github/workflows/release.yml`. It needs a GitHub Actions secret named `NPM_TOKEN` (an npm automation or granular token that can publish `@alexstep/doc-extract` and the `@alexstep/doc-extract-*` platform packages). The token is not stored in the repo. `workflow_dispatch` builds artifacts and does not publish.
- Keep `rustfmt.toml` (`tab_spaces = 2`). Run `cargo fmt` before finishing a Rust change.
- Cloud agents install toolchains and the native addon via `.cursor/install.sh`, referenced from `.cursor/environment.json`.
